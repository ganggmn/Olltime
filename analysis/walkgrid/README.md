# 보행로 5m 칸 (v1, 2026-11-27)

- 격자: 서울 생활인구 250m 칸(국가지점번호, EPSG:5179) 원점에 맞춘 5m 칸. 칸 (i,j) 왼쪽 아래 = (965500 + (69+i)·5, 1945750 + (41+j)·5).
- `cells_v1.b64`: 315×294 바이트(행 = j, 열 = i)를 deflate-raw → base64url. 값 0 = 빈 칸, 1~5 = 칸 안 보행 면적(1:<5㎡ … 5:≥20㎡), 6~10 = 같은 단계인데 위성 판독으로만 들어온 칸.
- `osm_exp3.txt`: OpenStreetMap(© OpenStreetMap 기여자, ODbL) 공원 경계·보행로·광장·건물·물·주차장. 레코드 = 종류+id;태그;구글 polyline(1e-5)!. `osm.py`로 읽음.
- 만든 방법(브라우저에서 계산, 위성 타일은 저장하지 않음):
  1. Esri World Imagery z19 타일 754장을 읽어 색(16단계³)×질감(7×7 밝기 표준편차 6단계) 표로 포장면 확률을 냄. 학습: OSM 광장·폭 3m 이상 길 = 포장, 길·건물에서 12m 넘게 떨어진 공원 안 = 아님, 아스팔트 자전거길 중심 1.5m = 포장(가중 3).
  2. 길 폭: OSM width 태그 → 없으면 5m마다 길을 가로질러 ±12m 단면에서 포장 구간 길이의 중앙값(3곳 이상·25% 이상 잴 수 있을 때) → 아니면 종류별 기본값(footway 2.8, path 1.5, steps 2.5, cycleway 3, service 4, pedestrian 5).
  3. 보행 면 = (OSM 길 × 폭) ∪ OSM 광장 ∪ (위성 포장면 중 보행로에서 2m 안에 닿고 150㎡ 넘는 덩어리) − 건물·주차장·물·경기장 바닥 − 손으로 뺀 곳 3개.
  4. 칸 안 보행 면적이 1㎡ 이상이면 칠함.
- 확인: 카카오맵 거리재기 2곳 — 몽촌호 동쪽 산책로 5m(위성 2.6m), 몽촌토성 잔디 길 2m(위성 3.6m). 폭은 ±2~3m 틀릴 수 있음.

## v2 (2026-11-27 밤)
- 위성 판독으로만 들어온 칸은 뺌. 칠하는 건 OSM 길 × 폭 + OSM 광장뿐. 위성사진은 폭 재기와 검사에만 씀.
- 폭: 길마다 5m 간격 단면을 여름(2025, 현재 World Imagery)과 잎 진 겨울(2015-03-16, Esri Wayback 릴리스 577) 사진 둘 다에서 재고, 잰 값의 중앙값을 그 길 전체에 씀. 하나도 못 잰 길은 끝점이 이어진 길의 폭, 그래도 없으면 종류별 중앙값.
  - 길이 기준: OSM 폭 태그 3.7km, 잰 값 19.2km, 이웃 길 0.3km, 종류별 0.4km.
- `cells_v2.b64`: 값 1~5 = 면적 단계, +0 위성에 포장 보임 / +5 나무에 가림 / +10 포장 안 보임(확인 필요). 칸 9,238개, 면적 기준 88.3 / 6.0 / 5.7%.
- 지붕(비스듬히 찍힌 것)과 겹친 칸 0.25%.
- 지도에 없는 포장면(두 사진 모두 포장, 길에 붙음, 150㎡ 이상) 38곳 2.3ha — 칠하지 않음.
- 카카오맵 확인: 몽촌호 동쪽 산책로 5m(우리 5.2m), 몽촌토성 잔디 길 한 지점 2m(길 중앙값 3.3m), 평화의광장 북쪽 길 약 13~14m(우리 11.4m, 축척 막대 어림).
- 페이지는 사이트 지도(src/data/map.svg) 위에 그림. 5179→지도 좌표는 1차 변환식(최대 오차 0.07 단위 ≈ 0.13m).

## v3 (2026-11-28 새벽): 지도에 없던 광장 넣기
- 위성사진 두 장(여름 2025, 잎 진 겨울 2015-03-16) 모두에서 포장면(칸의 70% 이상)이고 우리 길에 붙은 150㎡ 이상 덩어리 41곳(3.5ha)을 다시 찾았어요. 방법은 `plaza_candidates_v3.json`의 how.
  - v2 때 찾은 38곳 2.3ha와 기준이 조금 달라요(화소 판정 문턱 0.7, 균형 맞춘 확률).
- 41곳을 사진으로 하나씩 보고 나눴어요(사람 확인 전).
  - 광장·건물 앞마당·호수 전망대 23곳: 칠함. 980칸, 칸 안 보행 면적 약 2.2ha. 값 16~20(면적 단계 + 15).
  - 주차장·차도에 붙어 걷는 곳인지 분명하지 않은 15곳: 값 21~25, 페이지에 점선으로만 보이고 칠한 칸·면적에 넣지 않음. 365칸, 약 0.8ha.
  - 주차장·차도 3곳(0.1ha): 뺌.
- `cells_v3.b64`: v2 값 그대로 + 위 두 종류. 칠한 칸 10,218개.
- 칸 모양은 Esri 사진에서 그린 것(벡터 만들기에만 씀, 사진은 페이지에 싣지 않음).
